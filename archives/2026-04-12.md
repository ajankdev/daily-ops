### Unexpected €36.8k Google Cloud Gemini API bill after enabling Gemini — legacy Maps API key without restrictions got abused
**Source:** r/GoogleCloud

> **Category:** [AI_MODELS]
> **Summary:** A company enabled the Gemini API in their Google Cloud project, which led to a massive spike in API traffic and a €36.8k bill. The cause was identified as a legacy Maps API key without restrictions that was abused by bots after Gemini was enabled.
> **Impact:** The unexpected bill has significant financial implications for the company, and the incident highlights the importance of properly securing and restricting API keys to prevent abuse, especially when enabling new services like Gemini.
