### Bringing Rust to the Pixel Baseband
**Source:** Google Security

> **Category:** [AI_INFRA]
> **Summary:** Google's Pixel team has integrated a memory-safe Rust DNS parser into the modem firmware of Pixel devices, specifically the Pixel 10 series, to reduce security risks associated with memory-safety vulnerabilities. The team chose the hickory-proto crate and added no_std support to it, then compiled the Rust code to a staticlib and linked it to the modem firmware. This project demonstrates the use of Rust in low-level environments and lays the foundation for future integration of memory-safe code in the cellular baseband.
> **Impact:** The integration of Rust in the modem firmware improves the security posture of Pixel devices by reducing the attack surface associated with memory-safety vulnerabilities. This project also showcases the potential for using memory-safe languages like Rust in low-level environments, which can have a significant impact on the security and reliability of critical infrastructure.
