# Daily Digest: 2026-08-03

### Release 1.154.1
**Source:** KCC Release

> **Category:** [GCP_K8S_CORE]
> **Summary:** This release, 1.154.1, introduces new alpha resources for various Google Cloud services, including Apigee, Cloud Build, Dataplex, and more. It also adds new fields to existing resources, such as ComputeSubnetwork and NetworkConnectivityInternalRange. Additionally, the release includes reconciliation improvements, with opt-in direct reconciliation support for more resources. Several bug fixes are also included, addressing issues with resources like ComposerEnvironment, MemorystoreInstance, and ComputeBackendService.
> **Impact:** This release provides new features and improvements for managing Google Cloud resources using Config Connector, enhancing the overall user experience and reducing potential issues with resource management. The added support for direct reconciliation and new fields in existing resources can simplify the management of complex cloud infrastructures. However, the impact is primarily operational, as it mainly affects the configuration and management of cloud resources rather than introducing new services or capabilities that would directly influence application development or user experience.
