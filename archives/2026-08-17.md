### I found a weird production bug with Razorpay
**Source:** r/GoogleCloud

> **Category:** [GCP_K8S_CORE]
> **Summary:** The issue encountered was with a Cloud Run deployment using Razorpay, where the production environment was returning a 401 error due to mismatched key and secret versions. The deployed revision had pinned an old test version of the key, while the correct live secret existed in Secret Manager. Redeploying with both credentials on the same version resolved the issue.
> **Impact:** The bug had a significant operational impact, affecting payment processing in a live production environment, and highlights the importance of verifying the exact secret versions attached to deployed revisions in Cloud Run and Secret Manager.
